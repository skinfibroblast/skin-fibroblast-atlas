These are the code files for the pan-wound-healing-stages fibroblast atlas. 
#Figures and Sample data
The “Figure” folder contains the code for the figures, and the “Sample data” folder contains processed data that may be used in the Figure code.
# Data processing and Analysis
The “Data processing” folder contains code for basic analysis and quality control. 
The “analysis” folder contains part of the analysis code.  
The processed data used in “analysis” and “data processing” can be accessed via the following Figshare link: https://figshare.com/s/7b1f109957c565914871
